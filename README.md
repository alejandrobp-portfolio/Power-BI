# 📊 Portfolio de Business Intelligence

### Power BI · Python · Data Visualization · Business Analytics

Colección de proyectos de **Business Intelligence y análisis de datos** desarrollados para transformar datos en información clara y útil para la toma de decisiones.

Los proyectos incluyen el desarrollo de **dashboards interactivos, KPIs, análisis geográfico, visualizaciones, transformación de datos y pipelines de procesamiento con Python**, combinando distintas herramientas dentro de un mismo flujo de trabajo.

## 🛠️ Competencias aplicadas

**Power BI · Power Query · DAX · Python · Pandas · Data Cleaning · KPIs · Data Visualization · Geospatial Analysis**
